## Pengisian Data Awal (Dummy Data)
Untuk mengisi database dengan data percontohan (Penduduk, Berita, Pengaduan):
1. Login sebagai admin di `/login`.
2. Pergi ke menu **Pengaturan** di dashboard.
3. Pilih tab **Sistem**.
4. Klik tombol **Isi Data Dummy**.
